Este es el repositorio oficial del curso y libro definitivo para aprender a desarrollar aplicaciones Full-Stack modernas utilizando el **TALL Stack** (Tailwind, Alpine, Laravel, Livewire).

## 🚀 Sobre el Proyecto

Este curso ofrece una introducción desde cero a **Laravel Livewire 4**, diseñado para llevar tus habilidades de backend al siguiente nivel de interactividad. Aprenderás a automatizar procesos rutinarios bajo un esquema de componentes flexible, permitiendo una comunicación entre cliente y servidor increíblemente simple, eficiente y potente.

## 📚 ¿Qué aprenderás?

- **Reactividad Pura:** Actualización de la interfaz en tiempo real sin recargar la página.
- **Ecosistema TALL:** Dominio total de Tailwind CSS y Alpine.js integrados nativamente.
- **Componentes de Alto Nivel:** Gestión de estados, eventos, validaciones y carga de archivos.
- **Full-Stack Eficiente:** Desarrollo un 80% más rápido mediante atributos personalizados y scaffolding moderno.
- **Integración con IA:** Creación de asistentes de chat con IA y RAG.

---

## 🛠️ Estructura del Curso

El contenido está dividido en 5 fases estratégicas:

1.  **Fase 1: Cimientos y TALL Stack** - Instalación, configuración y creación de componentes base.
2.  **Fase 2: Interactividad y Datos** - Data binding, acciones, validación en tiempo real y carga de archivos.
3.  **Fase 3: Comunicación Avanzada** - Manejo de eventos, listeners y componentes anidados complejos.
4.  **Fase 4: Optimización y UX** - Filtrado dinámico, paginación reactiva e integración profunda con Alpine.js.
5.  **Fase 5: Proyectos Reales** - Datatables, CRUDs con IA, Blog, Carrito de compras y más.

## 💻 Requisitos Técnicos

Para ejecutar este proyecto, asegúrate de tener instalado:

- **PHP:** ^8.3
- **Composer:** Última versión.
- **NPM:** Para la gestión de activos frontend.
- **Base de datos:** SQLite (por defecto) o MySQL.

---

## ⚙️ Instalación y Configuración

Sigue estos pasos para poner en marcha el proyecto localmente:

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/libredesarrollo/curso-libro-livewire-4.git
    cd curso-libro-livewire-4
    ```

2.  **Configuración automática (Recomendado):**
    ```bash
    composer setup
    ```
    *Este comando instalará dependencias, generará la clave, ejecutará migraciones y compilará los activos.*

3.  **Ejecutar el servidor de desarrollo:**
    ```bash
    npm run dev
    ```
